# 本地发动机与推进剂库

`long-march.json` 和 `commercial.json` 是可编辑数据源。网页和小程序使用由它生成的本地文件，运行时不向卫星百科发送请求。不需要部署新的数据库服务。

首批 25 条型号/构型记录：2C、2D、2F、2F/G、3A、3B、3C、3B/E、3B/G2、4B、4C、5、5B、6、6A、6C、7、7A、8（助推配置未指定）、8 双助推、8 无助推、8A、11、12、12A。不是全历史型号或全部改型的完整收录。

新增 `commercial.json` 的 24 条型号/构型：SpaceX（猎鹰1、猎鹰9当前型号族及Block 5、重型猎鹰、星舰当前型号族及V1/V2），蓝箭（朱雀1、2、2E及其首飞配置、3），星河（谷神星1及海射型、2、智神星1），天兵（天龙2、3），中科（力箭1、2），东方空间（引力1），星际荣耀（双曲线1当前型及首飞型）。与长征合计49条，不代表全部已飞火箭的穷尽收录。

已飞型号可以采用当前已核实发动机作为型号参考，但不能据此断言旧任务实际用了当前改型。记录保留 `referenceBasis`、`flightEvidence` 和适用范围；失败首飞也是飞行记录。计划升级、跳跃验证器不自动视为完整运载构型。朱雀三号按官方首飞公告采用天鹊12A/15A，不套用计划中的12B/15B。

每条记录包含准确别名、芯级和助推器、推进剂、发动机名称/数量、适用构型与来源。发动机数量是**每个组件**的数量：例如长征五号的 4 枚助推器，每枚有 2 台发动机；组合发动机用“组”，集成系统用“套”，不把燃烧室数当成发动机台数。

发动机 `scope=model_family` 仅是型号族资料；不代表已核实这次任务的具体发动机后缀。2F/G 的发动机具体改型、长十一二至四级名称等没有核实的内容留空。没有自动套用条目中典型关机时间、推力、燃烧时间，也没有把计划中的发动机升级当成现役配置。逃逸、姿控等辅助发动机不参与当前主尾迹指数。

## 来源与核对

- 官方字段放入 `officialOverrides`，按具体构型、组件和字段覆盖百科值；编译器拒绝没有官方来源的覆盖。
- 卫星百科保留具体条目链接。2F 使用之前成功取得的修订 258880；其他条目此次通过搜索可读取的索引内容核对，`access=search_index`，没有虚构 MediaWiki 修订号。2026-11-23 直接 API/HTML 批量请求返回 403，未进行全站抓取。
- `checkedAt` 是本地核对日期，不代表原网页更新时间或对整页全部内容的核实。
- 长六三级的四氧化二氮/偏二甲肼及 YF-50E 来自百科具体条目；官方长六页面只确认前两级液氧煤油、三级常规发动机，因此官方覆盖只作用于前两级。
- 长八甲芯级燃料与两枚助推器由 2026-11-20 航天科技集团公告核对；发动机改型独立保留来源。
- 页面正常列来源，不提示资料差异。卡片仍只有简短推进剂摘要，发动机字段保存在底层数据中。
- 只整理事实字段及链接，不打包百科全文或图片。百科查询脚本的候选结果不能直接覆盖本库。

## 更新与生成

核对具体构型和来源后修改JSON，运行 `npm run propulsion:build` 更新网页模块，再运行 `npm run verify`。查询脚本只生成待核对资料，不直接覆盖型号库。微信小程序及其同步脚本不在本公开仓库中。

当前推进剂系数仍是原有未校准的敏感性范围；建立型号数据库不代表获得了各型火箭的实测云气亮度。

推进剂组合未核实的液体级使用 `liquid_unspecified`，不猜测常温双组元，也不施加燃料修正；发动机名称未知则留空。天龙二号末级的一甲基肼与偏二甲肼分开保存。重型猎鹰侧助推器与星舰串联的超重助推级分别建模，不以发动机数量直接放大指数。

当前所有燃料情景上限均保留几何权重，下限不同；等级依据上限，可能保持不变。尚未引入实测流量、颗粒排放或凝结参数，因此不能把新增发动机型号当作定量光学标定。

补充 Starship V3 / 星舰 V3 的精确名称识别：按官方猛禽系列资料确认两级液氧甲烷，参与相同燃料情景修正；不借燃料判断补写发动机数量、推力或时序。
