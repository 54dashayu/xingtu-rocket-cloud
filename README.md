## 能做什么

- 查看未来 30 天任务及过去 30 天、3 个月、半年、1 年档案；按国家、载人属性、发射机构等筛选。档案期限不等于已完整收录该期限内全部任务。
- LL2 优先，结合有来源的官方公告、航警候选和观测资料；名称、时间精度、发射方向、结果及可靠度分别处理。航警窗口不是已确认点火时间，未知资料不伪造为精确轨迹。
- 根据任务资料或明确标注的参考情景，展示动力段、留存尾迹、太阳照明、地影和地面观测条件；没有符合条件的历史演示资料时不提供误导性的 3D 入口。
- 简短显示芯级、上面级与助推器推进剂；本地型号库保存发动机、构型和来源。官方已核实型号资料优先于卫星百科补充资料，未知改型保持待核实。
- 气象按原观测/采样坐标查询，显示附近较大城市或方位距离辅助定位。远海、远距或无法定位时保留坐标，不把天气点移到城市中心。
- 报告与档案分标签；用户报告和媒体证实分别展示。照片只有经授权及审核才能公开，保留署名、来源与原水印。
- 竖屏统一底部导航和字号；3D 地球紧跟当前任务，地点等设置在下方。横屏保留地图与两侧任务/分析布局。

### 0036 的刷新修复

每次打开新文档读取一次数据，完成后不再每分钟或在切回前台时反复重载。筛选、倒计时和播放继续运行；可主动点击“刷新”。首次返回后台缓存时，最多额外补取 3 次（3、6、12 秒间隔），遵守服务端退避时间；失败仍保留可用列表和数据更新时间。后台采集/自动巡检不因此停止。

修复了替换任务对象后丢失已完成火箭云评估的问题。相同任务输入保留评估，时间、方向、推进剂等真实变化会重新评估；手动更新仍允许新的负结果替代旧提示，不能把“稳定显示”理解为锁定预测结论。

## 如何理解预测

火箭云指数是实验性关注度，不是实际可见概率，也不是水母云形态概率。几何、推进剂情景、天气和观测报道各有独立含义。

自 0035 起，不再用通用 70 km 高度或普通级间分离自动生成“水母云专属区域”。已核实上面级含低温推进剂组分，只能作为构型候选线索；芯级低温不能代替上面级证据。捆绑助推器分离与普通级间分离分别记录。缺少任务级组件、时序和形态资料时不给出专属区域，未知保守处理；普通几何分析、3D 和有来源的历史水母云记录仍保留。

推进剂系数尚未经过实测光学标定，不凭发动机数量扩大指数。3D 的暖色日照、阴影与过渡带用于解释照明关系，不能当作精确的大气散射亮度或真实云形态。

## 本地运行与测试

需要 Node.js 20+。服务端运行时无 npm 第三方依赖；Three.js 已作为带许可证的固定版本静态资源附带。

```sh
git clone https://github.com/54dashayu/xingtu-rocket-cloud.git
cd xingtu-rocket-cloud
npm run verify
npm run test:3d
npm run test:android-adapter
npm start
```

- `http://127.0.0.1:4173/`：独立日历；`/map.html`：整合地图/日历/分析/报告；`/3d/`：3D 页面。
- `public/` 是发布用共享源码，尤其 `public/3d/` 为当前维护版本，不用历史原型生成器覆盖。
- `src/` 提供发射数据、几何/天气/公告接口；`data/propulsion/` 为有来源的本地型号资料，`npm run propulsion:build` 更新网页数据模块。
- `platforms/android/`、`platforms/ios/` 为原生容器源码；各目录 README 说明构建方式。
- `prototypes/rocket-cloud-3d/` 是保留测试的历史实验，不是发布页生成来源。
- `analytics/`、`deploy/` 提供可选统计/审核服务及部署样例；部署时自行配置认证、路径、天地图密钥和服务权限。

仓库不附带生产发射缓存、用户报告、数据库、凭据、签名材料或内部发布记录。首次联网与上游限流可能影响数据取得；离线测试夹具不代表最新发射计划。小程序专属测试不分发，跨端对齐测试明确跳过小程序部分。
