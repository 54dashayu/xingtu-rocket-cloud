# 火箭云 3D模型

正式入口：https://space.bh1jss.net/rocket-cloud/3d/index.html 。运行 `node scripts/build-rocket-cloud-3d.mjs`（项目根目录）生成 `public/3d/` 静态页面，使用站内任务接口与共享算法。

原型入口：http://127.0.0.1:4187 。在本目录运行 `npm start`；首次复制到另一台机器先 `npm ci`。需要 Node.js 20+ 与 WebGL 浏览器。

## 日历联动

- 先保持原项目的日历服务运行于 4186。3D 服务只代理固定的任务列表只读接口，不接受外部代理目的地址。
- 本地 4186 日历仅对已证实历史任务与未来火箭云候选显示“3D模型”按钮，置于指数/状态之后，横竖屏均显示；任务卡片保持原有选择/详情行为；普通任务详情及二维地图任务详情保留“3D 预测 / 3D 回溯（本地实验）”链接。正式网页已接入；卡片入口为“3D模型”，原详情内“本地实验”链接已移除。返回日历保留任务ID与历史范围。
- 支持 `/?launch=<任务ID>&range=history` 深链接。历史与未来任务从各自列表取，不使用只支持未来任务的单任务接口。历史列表受现有日历收录范围限制，不能声称覆盖完整一年。
- 3D 页内按未来候选、全部未来、已证实历史、全部历史切换；分类变化后点击“加载任务”。无URL任务时默认加载第一项未来候选。指定任务未找到时明确提示，不替换成其他任务。
- 候选是现有火箭云初筛结果，不保证可见；已证实必须是过去已发射结果且有confirmed公开观测来源，普通用户报告不自动升级成已证实。
- 自动带入任务时间、场址、方向。匹配的有来源轨迹优先；否则通用参考轨迹。方向的来源/假设单独标注；历史缺少证据和方向时不生成虚假轨迹。
- 修改时间、场址或航向后标为自定义假设；观测点变化不改变任务身份。折叠参数内可恢复任务参数，或进入独立手动实验。
- 事件优先采用已验证任务推进资料的末次关机时刻；缺失事件明确标“估计”。一级分离、二级点火取通用双级模型，抛罩假设首次达到100 km，载荷分离假设末次关机后60秒。以上是教学条件而非型号标准；段外事件只列时间，不绘制虚假位置。

## 观测地点与定位

58个城市中心近似坐标，含省会、首府、直辖市、常见城市及港澳台城市；另有场址与自定义经纬度。

“获取当前位置”仅点击后调用浏览器Geolocation API；浏览器可能使用GPS、Wi-Fi或系统定位服务，不保证有GPS硬件。显示结果精度，点击应用后生效。拒绝、不可用和超时均保留选城/手填操作。请求后选择其他城市，会丢弃迟到的定位结果。应用设定后，所选坐标和候选观测时刻发送至本站天气接口，再由 Open-Meteo 查询；不持久化定位历史，不调用人口接口。真实定位授权留给用户点击，不在验收中读取实际位置。

## 显示与模型

地影柱默认显示；唯一显示开关为教学高度×2，默认真实高度。默认近发射场，保留全球视角切换；任务标题、状态、视角按钮共享紧凑标题区。桌面地图下方事件集中在左、数值与观测结论在右，释放高度给3D视图；窄屏自动上下排列。地面投影固定为当前时刻，左侧图内按钮放大、缩小和复位。晨昏双视图已移除，离线晨昏回归测试保留。

观测点结论覆盖当前轨迹与留存尾迹的全分析窗，以约1秒采样显示可见时段；滑块不改变全窗结论。不把本分析窗外推到整次实际飞行。

共用 public/map 的太阳、动力学、轨迹和可见区域算法。地球球形半径6371km，通用轨迹仅到150km，段末后跟踪已有尾迹300秒，不推断后续飞行。区域几何不含风、扩散、天气、地形、折射或散射亮度；所选观测地天气单独自动查询。真实任务无推进时序时，尾迹发射仅作示意。

太阳独立远景，视直径约0.53°；与地球不共用距离比例。箭头表示太阳→地球的平行入射光，地影圆柱近似不含半影。陆地轮廓复用public/map/land.json；Three.js固定0.170.0本地加载。
