# 数据与接口（0036）

LL2 为主要任务来源，官方公告补充任务身份、时间和结果；航警的时段和危险区仅用于待核实任务及方向约束。国内来源适配器包括中国载人航天、航天科技集团、海事局等公开页面；没有承诺任何单一源完整覆盖所有发射。来源记录与字段可靠度应一起查看。

地图使用部署者配置的天地图服务，失败时可回退本地 Natural Earth 简化底图。卫星百科提供推进剂补充事实，官方已核实资料优先，保存具体来源及适用构型。天气由本站代理按原观测坐标调用 Open-Meteo，iOS GeometryOnly 路径关闭天气。

## 数据流与缓存

后台定期采集、退避、去重和合并；日历及火箭云部署应共用原子快照，配置单写入者，其余服务只读。`deploy/launch-watchdog.py` 提供独立巡检/恢复流程，不能因前端停止轮询而停用。

客户端每个文档/数据集进行一次有界更新，缓存未完成时最多额外3次补取，尊重retryAt；状态结束后不再每分钟或切回前台重载，允许手动刷新。失败保留已有列表和最后数据时间。范围首次切换可以读取该范围，普通分类在现有列表中筛选。

## 常用 HTTP API

路径相对于部署前缀，线上日历为 `/launch/`，整合页面为 `/rocket-cloud/`。

| 路径 | 用途 |
|---|---|
| `api/launches?days=30` | 未来任务及数据时间/缓存状态 |
| `api/launches/previous?days=365` | 历史档案，期限不保证覆盖完整 |
| `api/launches/:id/cloud-assessment` | 任务几何/指数/天气评估，参数以服务实现为准 |
| `api/observer-weather` | 观测地点气象 |
| `api/map-config` | 运行环境配置的地图访问参数 |
| `calendar.html` / 日历订阅接口 | 订阅说明与ICS导出，非直接写入系统日历 |

任务身份、点火时刻与航警窗口不能混用；资料不足时显示待核实。媒体报道、用户报告和模型预测分开，不以报告数量自动确认真实轨迹或水母形态。

生产快照、报告照片及授权记录、访问日志、账号和凭据不入库；公开测试使用夹具。第三方许可见 [THIRD_PARTY](../THIRD_PARTY.md)。
