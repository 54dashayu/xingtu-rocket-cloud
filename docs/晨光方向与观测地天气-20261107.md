# 晨光方向与观测地天气改进

本轮是可检验的模型改进，并非以11月7日西昌任务完成实测标定。用户提供了定性反馈，尚没有同一任务多个地点的准确观测时刻、未看见记录、镜头方向与天气观测可供拟合。

## 天光筛选

原逻辑只检查尾迹受光、观测地太阳高度不超过−1°、仰角阈值。新增观测者→尾迹与观测者→太阳两条视线的夹角 E。球形地球半径6371km，太阳按无穷远方向处理。

参考阈值：`太阳高度上限 = −1° − 5° × max(0, 1 − E/90°)²`。上限从贴近太阳时的−6°平滑回到夹角≥90°时的−1°。这是我们选择的保守筛选参数，不是文献给出的火箭云可见阈值。它尚不计算尾迹辐射亮度、粒径相函数、气溶胶消光或肉眼/相机对比度。

规则对晨昏相同，逐时更新太阳位置；清晨变亮时通常更早退出。轨迹改变尾迹方向和受光，而非因火箭向东就给所有地点固定惩罚。东侧观测者如果向西看尾迹，并不等于朝太阳看。二维网格、3D单点及全窗判断、关注指数共用该规则。

科学参考仅支持天光随太阳高度、天空方向和大气状态变化这一机制，并不验证上述阈值：

- [Patat等，ESO-Paranal晨昏天空亮度测量](https://arxiv.org/abs/astro-ph/0604128)
- [ING晨昏亮度实测](https://www.ing.iac.es/astronomy/observing/conditions/skybr/twilight.html)

## 观测地天气

3D应用设定后调用本站 `/api/observer-weather`，只查询已应用观测点的经纬度；后台仍使用固定Open-Meteo源，不接受任意上游地址。首个候选观测时刻作为小时天气采样时间；无候选窗则标明“发射时刻天气参考”。天气不改变几何网格，也不把低云量推断为火箭云已出现。UI默认一条结果，详情显示小时数据、缺测与来源。换地点取消旧请求，且序号校验防止旧结果覆盖。

修复原天气缓存仅按一天的查询URL命中、可能复用错误小时结果的问题；现在缓存键包含请求时刻。客户端天气版本使用当前已有天气渠道；iOS首版的geometry-only禁用策略保留。
