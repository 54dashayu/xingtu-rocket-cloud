# 完整动力段与尾迹观测（构建 0031）

默认分析范围改为“完整动力段 + 尾迹”，不再在150公里高度截断。100公里和150公里仍可用于查看早期阶段。150公里不是转为水平飞行的统一高度；航迹俯仰与地面航程由任务资料或参考动力学决定。

## 计算方式

1. 有匹配本任务的轨迹与推进时序时，沿公开轨迹计算到最后关机节点；按燃烧区间生成尾迹，滑行期间不生成，已知再次点火后恢复。
2. 只有轨迹时，使用资料覆盖段，不外推位置。没有推进时序的连续喷气是假设，界面明确说明。
3. 没有轨迹但具备演示条件时，沿现有通用双级动力学积分到燃料耗尽。移除250公里提前停止条件；积分仍受时间上限、地面碰撞等约束。此情景并非型号遥测，也不保证入轨。
4. 各尾迹段独立保留最多300秒，并逐时重新计算太阳照射、地球遮挡、观测仰角及朝阳方向天光约束。关机后只计算已生成尾迹，不外推火箭位置。300秒是参考寿命，不是所有任务的实测寿命。
5. 地图显示当前仍存尾迹的可见范围。沿航向伸长、弯曲、分离或消失均由几何计算产生，不强制画成带状，也不把整个飞行期间的累计区域当作当前区域。

二维、3D及后台几何评估共用轨迹。3D外围范围与二维一致采用1度最低仰角，核心区为5度；低仰角容易被遮挡。默认时间轴延伸到轨迹段终点后300秒。

## 数值与验证

通用参考情景在太原场址、航向188.8度时，积分到约T+480秒，末点约202公里高、地面航程约1366公里。这仅说明本次模型延伸后的量级，不是11月19日任务的实际关机参数。

- 226项项目测试通过。
- 数值步长减半后，末点高度与航程差小于0.1公里。
- 测试覆盖分级滑行、再次点火、150公里以上尾迹、尾迹到期及二维/3D同一时刻结果一致性。
- 本地浏览器验证二维与3D的T+400秒（高于150公里）、T+600秒（关机后尾迹），3D播放/暂停及尾迹完全过期；截图留档于output/extended-flight。
- 预览地址：http://127.0.0.1:8796/map.html 。本地使用公开任务缓存快照；未接天地图配置，显示简化底图。

## 仍有的限制

没有任务数据时，通用火箭质量、推力、耗油与转弯程序会影响远段结果。尾迹采用地固静止参考，没有加入高空风、扩散、粒子散射亮度或实测寿命。天气单独评估观测地。因此更长范围表示有条件可见的几何范围，并不是更高的实际看到概率。
