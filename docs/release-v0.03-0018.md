# v0.03 build 0018 — 档案报道图片

在媒体证实任务的档案卡片中增加报道图片。CRS-35、星链 10-40 各收录两张官方照片，显示摄影者、来源与使用规则，点击可打开大图。长征六号甲两次任务保留原报道照片入口，暂不转载授权不明确的图片。

媒体图片按任务 ID 和日期关联，不计入用户报告数量，不改变任务证实状态或模拟参数。图片加载失败时保留来源与署名。横屏并排、手机单列，完整显示图片且不裁切水印。

前一构建 0017 已增加任务卡片与顶栏的 3D 入口，并将报告和档案分成独立标签；用户公开署名、地点与私人提交信息分开保存。

验证：0017 的 Node 测试 176 项、Python 测试 35 项通过；0018 档案相关测试 3 项通过。1440×900 与 390×844 浏览器检查图片、来源、无横向溢出。线上文件与源文件校验。
