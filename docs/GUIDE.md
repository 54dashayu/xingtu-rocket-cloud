# 使用指南（0036）

1. 从发射日历选择任务，可按国家、机构和载人属性筛选；回溯期限可选30天、3个月、半年或1年，收录可能不完整。
2. 地图演示查看发射时间、场址、推进剂和参考轨迹。使用播放、暂停、时间滑块和倍率查看当前时刻；未知资料仍保留待核实标签。
3. 在观测分析设置时间或观测地点，查看全分析窗与天气参考。气象地名是原采样坐标的定位说明，原坐标可展开查看。
4. 有可用资料的任务可进入3D。竖屏先看任务及地球，下方调整观测地点和参数；当前显示的形态与光照不能当作真实遥测。
5. 报告/档案分两个标签。报告允许大概时间地点，系统匹配候选；图片公开需要单独授权及审核。档案点击任务卡查看详情与署名图片。

首次打开会读取数据；若服务器正在更新缓存，仅有限补取，之后不因停留或切回前台反复重载。想重新核对任务可点击“刷新”，失败保留已有内容并显示更新时间。后台仍持续采集。

指数不是可见概率。“模型符合”“有用户报告”“媒体证实”含义不同。水母云构型候选不等于存在专属可见区域。天地图授权、网络及设备权限影响底图和定位；定位失败可改选城市或手填坐标。iOS 当前不提供天气模型。
