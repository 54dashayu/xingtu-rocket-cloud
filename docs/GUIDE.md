# 使用指南

[打开星途·火箭云预测](https://space.bh1jss.net/launch/rocket-cloud/)

## 先选一次发射

点击任务卡片，或者点击地图上的发射场。选择“未来 30 天”看近期安排，选择“回溯 30 天”看过去的任务。勾选“可能出现火箭云”，可以先挑值得留意的任务。手机竖屏时，地图下方是任务列表和分析，向下滑动即可查看。

国外发射同时显示当地时间和北京时间；中国发射只显示北京时间。计划可能改期，临近发射请再刷新确认。

## 播放模拟

点击“模拟发射”，看轨迹和蓝色观看区域随时间变化，也可以直接拖动时间条。

| 控件 | 用途 |
|---|---|
| ⏪ | 回到时间条起点，通常为发射前一分钟 |
| 模拟发射／暂停 | 开始或暂停播放 |
| 1×、2×、4×、10×、20× | 调整播放速度 |
| 回到 T0 | 回到发射时刻 |
| 在地图演示 | 放大轨迹并播放 |
| 地图上的“返回” | 回到之前的视角；没有之前的视角时回到世界地图 |

地图可拖动、滚轮缩放，手机可双指缩放。右侧的 100 / 150 公里是演示终点的高度，不是距离你多远；通常保留默认设置即可。

## 看懂地图

发射场圆点越大，近期任务越多。灰点是常驻场址，蓝点有近期任务，金色点包含值得关注的火箭云候选。

亮暗底色表示白天和夜晚，橙色线是模拟上升轨迹。蓝色覆盖区域表示当前时刻可能看到受光尾迹的地方，具体颜色对应右侧色标：

- 浅蓝边缘：尾迹靠近地平线，更容易被建筑、山地和云层挡住。
- 较深的蓝色：满足相应天空明暗和观看角度条件。
- “水母云关注区”：可以重点留意，但不代表一定呈现水母形状。

蓝色不代表晴天。接着查看“模型与天气”，了解采样地点的遮挡情况；显示待更新或缺少数据时，不能当作天气良好。

## 时间未定时怎么试

选中时间待定的未来任务，在右侧填写**发射地当地日期和时间**，可参考旁边的晨昏时间，再点“按此时间演示”。这只改变模拟，不会改动公布的发射计划。点击“恢复待定”可撤销。

## 航警方向参考怎么用

若右侧出现“航警方向参考”，展开后可以选择候选“用作模拟约束”。它提供一个可能的方向范围，仍需核对是否对应本次任务；点击“恢复建议”即可撤销。不需要调整时，保持默认设置即可。

## 其他常见问题

**没有蓝色区域，是不是一定看不到？** 当前模拟可能还未满足条件，也可能缺少发射时间或轨迹资料。先播放到后面的时刻，并看右侧提示。

**“已证实火箭云”是什么意思？** 这次发射有已收录的公开观测报道。没有标记，不等于当时没有火箭云。

**如何提醒自己？** 点击顶部“订阅日历”，按提示添加到日历软件。它记录发射安排，并不是对火箭云必然可见的承诺。

出发前再次核对发射时间和当地天气。实际观看还会受真实航迹、云层和现场遮挡影响。

如想进一步了解计算方法，可阅读[模型技术说明](MODEL.md)和[数据来源](DATA.md)。
