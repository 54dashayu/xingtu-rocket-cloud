## 用户可见变化

- 日历任务卡片的“报告”“3D模型”统一高度、字号、圆角与内边距；触屏保留较大点击区域。
- 历史任务仅在具备明确时间、坐标且当前分析模型可生成轨迹时显示 3D 模型按钮。无相应资料的美国太空军 432 任务不再显示该入口；用户报告或媒体资料支持的参考回放仍保留。
- 报告授权精简为必选“提交核对”和选填“公开照片”。默认不勾选；公开仍须审核。保存期限等细节折叠，不改变原有授权边界。
- 新增“数据来源”页面，日历明确标注 The Space Devs / Launch Library 2。说明 Open-Meteo、天地图与照片的各自使用条件。
- 已授权公开的网友照片在画面外自动加注公开署名与来源，保留原图内容和水印；私人原图不改写。撤回公开授权后不返回缓存副本。
- 现有四张可使用的 NASA / DVIDS 档案照片增加署名和来源；其他新闻仍链接原文。照片及第三方资料不因代码开源而取得 MIT 授权。

## 平台对齐约定

安卓、iOS 均沿用相同来源说明与授权选项。免费使用不代替数据源条款；Open-Meteo 按免费非商业场景使用并保留署名与额度管理。天地图跨端授权由项目所有者确认，仍保留来源及审图号。

照片公开接口与字段不变：publicCredit / publicPlace / publishConsent。仅审核通过、授权仍有效且未过保存期限的照片可公开；图片端点现返回带署名的衍生图，客户端无需重复打水印。勿把 private nickname、报告原文或精确坐标放入公开署名。原作者与提交者可能不同。

移动端按各自线程现有发布流程更新，本次网页发布不代表 App Store / 安卓渠道已经发布。
