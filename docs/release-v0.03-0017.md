# 网页版 v0.03 构建0017

2026-11-07

- 所有符合“可能出现火箭云”筛选条件的任务卡片提供3D入口，包括时刻待定任务。顶部新增“火箭云3D模型”，沿用当前所选任务。
- 报告与档案拆为独立标签；切换标签保留未提交内容，支持键盘切换。
- 档案展示媒体证实的任务及关联用户报告的任务，并提供回放、3D入口。用户报告关联不自动变成媒体证实。
- 获授权、审核公开的照片展示关联任务、公开地点、提交者公开署名和版权归属；加载失败仍保留署名。保留原图可见水印，不裁剪。
- 新报告单独提供可选的照片公开署名、公开地点；未授权及旧报告的原始姓名、地点、精确坐标不公开。历史未提供公开署名的照片显示版权归原提交者。
- 保留服务器已有的管理员任务关联及城市辅助匹配功能，并将档案需要的关联字段同步入仓库。

验证：176项 Node 测试、35项 Python 测试通过；1440×900与390×844浏览器检查标签切换、表单保留、筛选任务3D入口、图片失败时版权文字及当前任务3D跳转。没有向生产环境提交测试报告。
