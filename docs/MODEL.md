# 模型说明（0036）

本工具用于解释火箭尾迹受光与地面观看条件，不提供实际可见概率或实际轨迹保证。发射资料、几何模型、气象与观测报道分别保存。

## 轨迹、尾迹与太阳

有匹配任务及时间的飞行资料优先；缺失资料使用明确标注的参考动力学和航向情景。默认覆盖可用动力段，并跟踪停止喷气后留存的尾迹；100/150 km 可选截点不是所有任务的固定终点。真实速度、俯仰律、级段时序、姿态、风和扩散资料不足会限制可用范围。

每个采样时刻联合判断尾迹受光、地面天色与视线仰角。地平线以下的尾迹不会仅因场址接近晨昏线就成为可见；清晨逐渐变亮和傍晚逐渐变暗通过时变太阳几何参与计算。地图的当前区域与观测点全分析窗结论是不同时间口径。

3D 区分受光与地影轨迹，展示暖色日照和柔和过渡。过渡带是教学近似，未求解完整大气辐射传输；不据此声称测得云团亮度。

## 推进剂与构型

`data/propulsion/` 保存芯级、上面级、捆绑助推器、发动机与明确别名。未知改型不以短前缀套用；型号族资料不自动成为某次发射的实际配置。官方已核实字段优先于百科补充字段。

指数按可用的任务级组件喷气时段应用燃料敏感性范围；缺少时序时采用注明边界的情景。燃料不能抵消地影或白昼，未核实燃料采用中性权重，不因发动机数量直接增加亮度。系数没有实测光学标定，分值不是出现概率。

## 水母云：候选与证据分开

0035 已取消依据通用分级参考高度或 70 km 阈值生成专属水母区域的做法。`public/map/morphology.js` 输出构型候选、未知或不建议等状态，不输出任务级形态几何区。

- 已核实上面级含低温组分可作为候选线索，不保证水母形态。
- 仅芯级使用低温推进剂，不能替代上面级证据。
- 捆绑助推器分离独立记录，不能拿普通串联级间分离或估计事件冒充。
- 任务组件、分离/喷气时序或形态资料不足时，不创造专属区域。
- 有来源的真实历史观测记录保留，不能被“预测不建议”反向否认。

这些是产品的保守证据规则，不是关于所有火箭云的物理必要充分定律。

## 气象与资料状态

Web/Android 气象用于遮挡参考。显示城市或方位距离只改变定位文字，查询点、天气值和原坐标保持不变；远海和远距点不强称城市附近。iOS 当前 GeometryOnly 路径关闭天气。

媒体证实、软件用户报告、待核实航警任务和模型预测分别标注；未经审核的用户报告不等于已证实事实。有限采样、误差、来源和参考模拟标签应随结果一起阅读。

## 0036 的状态管理

相同任务输入保留已完成评估；资料变化则重新评估。单文档加载后无周期/前台自动列表刷新，有限缓存补取不等于永久轮询。主动刷新和首次异步评估仍能改变提示，不能以界面稳定代替科学准确度。
