# iOS 容器源码

原生工程版本 `0.03` / build `19`，使用 WKWebView 加载在线火箭云页面。0036 是本次共享网页版本，不是新上传的 iOS 构建号；本仓库和 Release 不代表 App Store 已审核通过或正式发布。

当前使用 GeometryOnly 标记，天气关闭，保留几何与3D演示。包含启动加载/重试、系统安全区域、ICS文件分享与定位/照片用途说明。正式账号、签名与审核资料不随源码分发。

模拟器：在本目录运行 `./scripts/build-simulator.sh`，需完整 Xcode。真机构建请在 Xcode 配置自己的开发团队及 Bundle ID；公开工程不预填开发团队。不要把模拟器启动或网页按钮存在视为真机权限、分享或审核验收。
